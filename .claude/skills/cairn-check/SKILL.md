# Check Cairn

Answer the user in French (keep technical terms in English). Run from the repo root, one call, long timeout (600000):

```sh
(cd CairnCore && swift test 2>&1 | grep -E "error:|failed|Executed|passed|✘|Test run" | tail -20)
xcodegen -q
xcodebuild -scheme Cairn -destination 'platform=macOS' -derivedDataPath build build 2>&1 \
  | grep -E "error:|BUILD (SUCCEEDED|FAILED)" | tail -20
```

- `Cairn.xcodeproj` is generated by `xcodegen` and not versioned: always regenerate before building, a new file is
  otherwise missing from the project.
- On failure: show the first error with `file:line`, fix the root cause, re-run. Do not stop at the first green half.
- SourceKit diagnostics such as `No such module 'CairnCore'` in the editor are noise when `xcodebuild` succeeds.
- Report: test count and result, build result. Nothing else.

UI changes also need a look in the running app: use the `cairn-run` skill.
